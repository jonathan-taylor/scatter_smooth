# Data

`bikeshare.csv` is the ISLR2 version (also ISLP's `Bikeshare`) of the UCI Bike
Sharing data, hourly counts of bike rentals in Washington, D.C. in 2011:

Fanaee-T, H. and Gama, J. (2013). Event labeling combining ensemble detectors
and background knowledge. *Progress in Artificial Intelligence*, 2, 113-127.
https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset

It is licensed under the Creative Commons Attribution 4.0 International
(CC BY 4.0) licence. Load it with `scatter_smooth.datasets.load_bikeshare()`.
